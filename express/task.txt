Task 2: The "Complex User Profile" (Nested JSON Object)
Create a route /api/profile. Do not use a separate file, create the data directly inside the route.

Goal: When the user hits this route, they should receive a single JSON object. But this object must be nested.

Format required: It must have normal strings (name, email), an Array for skills (e.g., ["HTML", "CSS", "JS"]), and an Object for address (e.g., { city: "Delhi", pincode: 110001 }).

Task 3: The "Product Finder" (req.params & 404 Error handling)
Create an array of products in server.js:
[{ id: 101, name: "Keyboard", price: 500 }, { id: 102, name: "Mouse", price: 300 }]

Goal: Create a route /api/products/:id.

Condition 1: If a user visits /api/products/101, remember to convert req.params.id from String to Number, find the product, and send its data.

Condition 2: If the user visits /api/products/999, the server must send a 404 status code with this exact JSON: { error: true, message: "Product missing!" }.

Task 4: The "Category Filter" (req.query)

Condition 1: If the user visits just /api/food, send the entire array.

Task 2: The "Bank Account" Lookup (The parseInt Trap)

Setup: Create an array containing data for 3 bank accounts. Required keys: accNo (this must be a Number, e.g., 101, 102), accountHolder, and balance.

Goal: Create a dynamic route /api/account/:accNo.

Condition 1: When a user visits /api/account/102 in their browser, they should receive the JSON details of that specific account.

The Trick: The req.params.accNo received from the URL is always a String (e.g., "102"), but the accNo inside your array is a Number. The main goal of this task is to understand why you must convert the String into a Number (using parseInt() or Number()) before using the Array.find() method.

Task: The "Student Profile Updater" (Params + Body Combo)

Setup: Create an array of students directly in your server.js file:
[{ id: 1, name: "John", course: "HTML" }, { id: 2, name: "Sarah", course: "CSS" }]

Goal: Create a POST route: /api/students/:id

The Concept: This task combines two concepts. You need req.params to know WHO to update, and req.body to know WHAT new information to put there.

Condition 1: A user sends a POST request to /api/students/1 using Thunder Client. In the JSON body, they send: { "newCourse": "React" }.

Condition 2: Your server must extract the id from the URL, find the matching student in the array, and update their course to the new one sent in the body.

Condition 3: Send the updated student object back in the JSON response.
